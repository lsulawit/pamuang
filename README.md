# มนุษย์ป้าม่วง 💜 — Purple Auntie Deluxe

**เกมแนวตั้งบนมือถือ** สไตล์ภาพการ์ตูน 3D มีแอนิเมชั่น CSS (กล้องขยับเบา ๆ กลีบดอกไม้ลอย คีย์บอร์ดวิ้ง และจังหวะที่ป้าหันมา) — เล่นได้แม้ยังไม่ตั้งค่าบัญชีหรือชำระเงิน

## ขั้นตอนเดียวกับ Waralak Brain Game

**GitHub → Vercel → Supabase (เพิ่มเมื่อพร้อม)**

1. แตกไฟล์ ZIP นี้ แล้วเข้า [github.com](https://github.com) → **New repository** ชื่อ `purple-auntie-game` เลือก Public
2. ใน Repo เลือก **Add file → Upload files** แล้วลาก *ทุกไฟล์และโฟลเดอร์* ใน ZIP (ต้องมี `index.html` อยู่ที่ root ไม่อยู่ในโฟลเดอร์ซ้อน) → **Commit changes**
3. เข้า [vercel.com](https://vercel.com) → **Add New → Project** → เลือก **Import Git Repository** เลือก `purple-auntie-game`
4. **Framework Preset: Other** / ไม่ต้อง Build / Output Directory ว่าง → **Deploy** แล้วนำลิงก์ `https://...vercel.app` ไปแชร์
5. หากไม่ต้องการ Vercel ใช้ GitHub Pages ได้ที่ **Settings → Pages → Deploy from a branch → main → /(root)**

## ไฟล์สำคัญ (โครงแบบเดียวกับ Waralak Brain Game)

- `index.html` — หน้าเริ่มเกม เลือกด่าน คีย์บอร์ด ร้านค้า แรงค์ โปรไฟล์ ภาพหลัก **ฝังในไฟล์นี้** เพื่อป้องกันภาพไม่โหลดเมื่ออัปโหลด
- `styles.css` — สี การจัดวางหน้าจอ 9:16 แนวตั้ง เอฟเฟกต์ UI และธีมคีย์บอร์ด
- `game.js` — เกมเพลย์ คะแนน ไอเทม สกิน เล่นกับเพื่อน ร้านค้า และ localStorage
- `knowledge.js` — ประโยคแต่ละด่าน กติกา เวลา และระดับความยาก
- `three-lab.js` — เอฟเฟกต์ฉาก 2.5D และกลีบไม้เคลื่อนไหว (ยังไม่ใช่โมเดล Three.js แบบ 3 มิติจริง)
- `supabase-config.js` — ตั้ง URL และ *publishable/anon key* ของ Supabase (อย่าใช้ `service_role`)
- `supabase.js` — เชื่อม Auth, Leaderboard, คะแนนห้องท้าเพื่อน ใช้ได้เมื่อตั้งค่าข้างบน
- `supabase-schema.sql` — โครงสร้าง DB และ RLS ที่ต้องรันบน Supabase ก่อนเปิดฟีเจอร์ออนไลน์
- `assets/*.webp` — ไฟล์ต้นฉบับภาพเกม (ภาพหลักสำรองฝังใน `index.html` แล้ว)

## เกมที่ใช้เล่นได้ทันที

- หน้าเริ่มเกม, ด่าน 5 ด่าน, โหมดแรงค์ออฟไลน์, ตัวจับเวลา, จังหวะไฟเขียว/เหลือง/แดง, แพ้ถ้ายังพิมพ์ตอนป้าหันมา, คะแนน และเหรียญ
- คีย์บอร์ด 6 ธีม (ม่วง ชมพู มิ้นต์ กาแล็กซี ทอง ลูกกวาด) ซื้อด้วยเหรียญที่หาในเกมได้
- ไอเทมช่วยเล่น: 🙈 ปิดตาป้า, ❄️ หยุดเวลา, ✨ ช่วยพิมพ์ (ไม่ใช้ในโหมดแรงค์เพื่อความยุติธรรม)
- บันทึกการเล่นในเบราว์เซอร์, แชร์ลิงก์ท้าเพื่อน, ระบบตั้งชื่อ และความยาก
- เอฟเฟกต์และเสียงสังเคราะห์ด้วยเว็บ ใช้งานได้โดยไม่ต้องโหลดเสียงภายนอก

## เปิดระบบบัญชีและอันดับออนไลน์ (Supabase)

1. [supabase.com](https://supabase.com) → New project (สร้างโปรเจกต์ของคุณ ไม่ใช่ของคนอื่น)
2. SQL Editor → วางเนื้อหาจาก `supabase-schema.sql` → Run
3. Settings → API / Project Settings → คัดลอก **Project URL** และ **publishable / anon key** ไปใส่ `supabase-config.js`
4. Authentication → Providers → เปิด Email (หากต้องการ Google ให้ตั้งค่า OAuth และ URL redirect ตามคู่มือ Supabase)
5. Authentication → URL Configuration → เพิ่ม Vercel Site URL และ Redirect URLs สำหรับโดเมนจริง
6. Commit ไฟล์ตั้งค่าใหม่ใน GitHub → Vercel จะ Deploy อัตโนมัติ แล้วทดลองสมัครสมาชิก/ยืนยันอีเมล/ส่งคะแนน

> **สำคัญ**: โหมดจัดอันดับออนไลน์ในชุดนี้เป็น **BETA** — คะแนนถูกส่งจาก JavaScript ฝั่งผู้เล่นและยังปลอมแปลงได้ ห้ามใช้ตัดสินรางวัลเงินจริงก่อนมีเซิร์ฟเวอร์ตรวจสอบการแข่งขัน

## ระบบเติมเงินจริง (วางโครง ยังไม่เปิดชำระ)

ร้านค้ามีแคตตาล็อกจำลองเพื่อวางแผนราคา แต่ไม่ได้รับชำระเงินจริง และไม่มีการให้สิทธิ์จากยอดชำระจำลอง การขายจริงจำเป็นต้องเพิ่ม payment gateway (เช่น Stripe หรือผู้ให้บริการท้องถิ่นตามประเทศที่จดทะเบียน), ฝั่งเซิร์ฟเวอร์, webhook ที่ตรวจ signature, ตาราง purchases/entitlements, การยืนยันใบเสร็จ และนโยบายการคืนเงิน/ความเป็นส่วนตัว **ห้ามฝังคีย์ลับ payment ใน GitHub หรือ JavaScript ของเว็บ**

## ทดสอบ

เปิด `index.html` ในเบราว์เซอร์ Chrome/มือถือได้เลย หรือใช้ `python -m http.server 8000` แล้วเข้า `http://localhost:8000` สำหรับการทดลองเว็บ.

การติดตั้งบน Home Screen รองรับ manifest แต่การล็อกการหมุนจอ 100% ขึ้นกับระบบของเครื่อง/เบราว์เซอร์ เว็บจะแจ้งให้หมุนกลับเมื่อเปิดในแนวนอน
