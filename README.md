# มนุษย์ป้าม่วง 💜 — เกมแนวตั้งสำหรับ GitHub Pages

เกมใหม่จากโปรเจกต์เดิม ปรับกราฟิกให้เหมือนภาพตัวอย่างที่ให้มา: สไตล์การ์ตูน 3D สีม่วง ฉากตรอกดอกไม้ ตัวละครป้าม่วงและน้องจิ๋ว พร้อมระบบเกมทำงานจริง **เปิดเว็บแล้วเล่นได้เลย ไม่ต้องติดตั้ง ไม่ต้องใช้ API key**

## เล่นยังไง

1. กด **เริ่มเล่น** หรือ **เลือกด่าน**
2. ช่วงป้าย **สีเขียว** แตะคีย์บอร์ดในเกมเพื่อพิมพ์ประโยค
3. ช่วงป้าย **สีเหลือง** ป้าจะหันมา เตรียมหยุด
4. ช่วงป้าย **สีแดง** ห้ามพิมพ์! ถ้ากดปุ่มจะถูกจับได้และแพ้
5. พิมพ์ **5 ประโยค** ให้เสร็จก่อนหมดเวลาเพื่อรับคะแนน ดาว และเหรียญ พร้อมปลดล็อกด่านต่อไป

มี **5 ด่าน**, 3 ระดับความยาก, โหมดแตะพิมพ์ง่ายและพิมพ์จริง, แป้นพิมพ์ไทยบนจอ, ทางเลือกใช้แป้นพิมพ์อุปกรณ์, หน้าแพ้/ชนะ, เสียงเตือน, ระบบสั่น, พักเกม, สถิติและดาวบันทึกใน localStorage ส่วนตัว ไม่มีข้อความใดถูกส่งให้คนอื่น

ในโหมด **พิมพ์ง่าย** แตะแป้นใดก็ได้เพื่อเติมตัวอักษรถัดไป เล่นได้ลื่นบนมือถือ ส่วน **พิมพ์เอง** ต้องกดให้ตรงจริง สามารถแตะหลอดไฟช่วยเติมอักษรได้ (หัก 5 คะแนนต่อครั้ง) หรือกด “ใช้แป้นพิมพ์ของเครื่อง” สำหรับพิมพ์ภาษาไทยแบบมาตรฐาน

## อัปโหลดลง GitHub Pages

1. แตกไฟล์ ZIP นี้ออกก่อน
2. เปิด GitHub สร้าง Repository ใหม่ เช่น `purple-auntie`
3. เลือก **Add file → Upload files** แล้วอัปโหลด **ไฟล์ทั้งหมดภายในโฟลเดอร์ที่แตก ZIP** รวมโฟลเดอร์ `assets` ไม่ต้องอัปโหลด ZIP อย่างเดียว
4. กด **Commit changes**
5. เข้า **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**
6. เมื่อเว็บเผยแพร่แล้ว เปิด `https://USERNAME.github.io/purple-auntie/` (แทน `USERNAME` ด้วยชื่อ GitHub ของคุณ)

`index.html` ต้องอยู่ **ราก repository** และโฟลเดอร์ `assets` ต้องอยู่ระดับเดียวกัน ไม่เช่นนั้นภาพจะไม่ขึ้น

## เรื่องการล็อกแนวตั้ง

- เว็บไซต์แสดงเกมเป็นกรอบ **แนวตั้ง** เสมอ
- เมื่อถือโทรศัพท์แนวนอน จะขึ้นป้าย **ให้หมุนมือถือกลับแนวตั้ง** และพักเกมโดยอัตโนมัติเมื่อหน้าต่างสูญเสียโฟกัส
- รวม `manifest.webmanifest` ระบุ `orientation: portrait` เมื่อเพิ่มไปหน้าจอหลักบนอุปกรณ์ที่รองรับ
- มีการร้องขอ Screen Orientation API เมื่อต้องเริ่มเล่น แต่ **Safari/iOS ทั่วไปไม่อนุญาตเว็บไซต์ล็อกการหมุนเครื่องทางระบบ** จึงใช้หน้าจอบังคับแนวตั้งแทน

## แก้ไขเกม

- `index.html`: โครงสร้างหน้าเกม
- `style.css`: สีม่วง ปุ่มสไตล์ 3D ขนาดจอ และแอนิเมชัน
- `game.js`: ระบบเล่น เซฟคะแนน และปุ่ม
- `engine.js`: ประโยคทั้ง 5 ด่าน เวลา กฎเกม
- `assets/`: ภาพจากตัวอย่างที่ผู้ใช้ให้มาและภาพดีไซน์เกมที่สร้างสำหรับโปรเจกต์นี้
- `manifest.webmanifest`: การเพิ่มเป็นแอปบนหน้าจอหลัก

เปลี่ยนประโยคใน `engine.js` ตรง `LEVELS` ได้ตามใจ ทุกอย่างเป็น HTML/CSS/JS แบบ static ไม่ใช้ CDN หรือไลบรารีภายนอก

## ทดสอบ

เปิด `index.html` ได้โดยตรง หรือใช้ `python -m http.server 8000` แล้วเปิด `http://localhost:8000` เพื่อทดสอบระบบ PWA บน localhost

```bash
npm test
```

กราฟิกเป็น **ภาพสไตล์ 3D ที่เตรียมไว้** และเคลื่อนไหวด้วย CSS ไม่ใช่โมเดล WebGL 3D realtime เพื่อให้ใช้ได้บน GitHub Pages และมือถือทั่วไปโดยไม่ต้องโหลดโมเดลขนาดใหญ่
